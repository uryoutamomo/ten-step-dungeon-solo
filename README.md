# 10歩ダンジョン ひとり旅

原作カードの絵柄と「剣・盾・魔法のコンボ」「消える足跡」「宝を持って生還する」ルールをもとにした、スマートフォン向けの新作一人用ゲームです。

**遊ぶ: https://uryoutamomo.github.io/ten-step-dungeon-solo/**

既存の `ten-step-dungeon` とは別のリポジトリ・公開URL・途中保存領域を使います。ログイン・インストールは不要です。

## 遊び方

1. 毎回変わる道を選び、最大10歩先の宝箱を目指します。
2. 手札4枚から、敵の指定する剣・盾・魔法を選びます。同時に2枚出す一撃か、複数ターンのコンボで勝利。出せないときは不要な札を1枚交換します。
3. 仲間を3体集めて6歩目に来ると伝説の剣を抜けます。ボスを一撃で倒せます。仲間は通常の敵と1対1で相殺する使い方もできます。
4. 灯りは36。移動・戦闘・交換・剣を抜く行動で消費します。実時間では減りません。スライムが消した足跡は帰り道の移動コストが2になります。
5. 10歩目のボスを倒したら、金銀財宝か羽の靴を選択。羽の靴は灯り1で最大3歩戻れます。
6. 灯りが尽きる前に入口へ戻れば生還。途中で引き返しても構いません。

持ち帰った金銀財宝5、ラスボス3、10歩達成2、羽の靴1の褒章を合計します。どれかがあれば、持ち帰った仲間1体につき1加算。最高記録は生還したときだけ更新します。

原作の対人競争、よこどり、帰還後カウントダウンはソロ用に置き換えています。原作カードの文面と画面の説明が異なる場合、このソロ版の説明を使います。帰りの戦闘はありません。

## スマホと保存

- 縦画面で、手札と行動ボタンを画面下側に配置。ドラッグやホバー操作は不要です。
- 原作カードをタップすると拡大。右上の「？」に詳しい遊び方があります。
- 手札選択・戦闘・帰還に短い合成効果音。最初はOFF、右上でONにできます。
- 自動保存と最高記録はこの端末・このブラウザに保存。別の端末とは同期しません。
- Safariでは「共有 → ホーム画面に追加」でアプリアイコンから起動できます。オフライン動作は保証していません。
- `ten-step-dungeon-solo:journey:v1` / `ten-step-dungeon-solo:best:v1` の2キーのみ使用。

## 開発

Node.js 22.13以降。

```sh
npm ci
npm run dev -- --host 127.0.0.1
npm test
node scripts/check-mutations.mjs
npm run lint
npx tsc --noEmit
npm run build
npm run export:pages
```

GitHub Pages の配信元は `main:/docs` です。`export:pages` はReactのクライアントコードをまとめ、画像を同じ公開ディレクトリにコピーします。サーバー機能・APIキー・外部通信・アクセス解析はゲームに含めていません。開発用Sites環境は公開先として使用していません。

## 構成と出典

- `app/game.ts`: 画面から独立した状態遷移、シード付き乱数、保存検査。
- `app/page.tsx` / `app/globals.css`: スマホ向け画面、手札操作、保存、効果音。
- `public/cards/`: ユーザー提供の1〜10枚目のPDFから抽出した38種類のカード面。重複カードは省いています。対応表は `scripts/card-sources.json`。
- `public/og.png`: この新作のために生成した共有用画像。
- `tests/game.test.mjs`: 誤操作、足跡、戦闘、宝の排他、帰還、破損保存、300通りの自動プレイ。
- `scripts/check-mutations.mjs`: 6種類の意図的な誤実装を検出する検査。

PDF全体・メール・ダウンロード元情報は公開物に含めていません。カード画像の権利は各権利者に帰属し、このリポジトリでの公開は第三者への素材再利用許諾を意味しません。
